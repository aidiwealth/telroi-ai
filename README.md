# Telroi — Nuxt 3 Site

Marketing website for Telroi, the AI-native voice infrastructure platform.
Built with Nuxt 3, Vue 3, and TypeScript. Static-site generated by default.

## Stack

- **Nuxt 3** — framework with file-based routing, auto-imports, SSR/SSG
- **Vue 3** with `<script setup>` Composition API
- **TypeScript** for the composables and translations
- **No CSS framework** — design tokens + scoped component styles
- **Static generation** — site builds to plain HTML/CSS/JS, deploys anywhere

## Quick start

```bash
npm install
npm run dev          # local dev server at http://localhost:3000
npm run generate     # static build → .output/public
npm run preview      # preview the static build
```

## Design system

Three layers in `assets/css/`:

1. **`tokens.css`** — design tokens as CSS variables. Change brand colors,
   fonts or container width here and the whole site updates.
2. **`base.css`** — reset, body defaults, the `.wrap` container, scroll-reveal
   transitions for `.reveal` elements.
3. **`components.css`** — shared UI primitives: `.btn`, `.kicker`, `.sec-head`,
   `.closing`, `.live-chip`. Component-specific CSS lives scoped inside its
   `.vue` file.

| `--ink-soft` | `#5b5b62` | Secondary text, ledes |
| `--paper` | `#ffffff` | Page background |

### Typography

- **Fraunces** (variable serif) — display headlines, italic emphasis
- **Geist** (sans) — body, UI, mono-tagged labels

## Adding a new page

1. Create `pages/new-page.vue`
2. Use the shared components:

```vue
<template>
  <div>
    <ProductHero
      kicker="My Page"
      title-start="Headline"
      title-em="emphasis."
      lede="One short sentence."
    />
    <CapabilityRail
      kicker="Capabilities"
      title-start="Built around"
      title-em="something"
      :capabilities="caps"
    />
    <EditorialCallout label="Why" text="Editorial moment with <em>italics</em>." />
    <ClosingCta cta-text="Talk to sales" />
  </div>
</template>

<script setup lang="ts">
useHead({ title: 'My Page — Telroi' });

const caps = [
  { title: '...', body: '...', icon: '<path d="..."/>' }
];
</script>
```

That's it — the layout, nav, footer and styles all wrap automatically.

## Translations

All UI copy goes through `useI18n()`. In a template:

```vue
<script setup lang="ts">
const { t } = useI18n();
</script>

<template>
  <h1>{{ t('hero.title1') }}</h1>
</template>
```

To add a translatable string, add a key to **all four languages** in
`utils/translations.ts`. The footer language switcher persists the choice in
`localStorage` and updates the `<html lang>` attribute reactively.

Languages supported: `en-US`, `en-GB`, `es-ES`, `fr-FR`.

## Intercom

The Intercom widget is loaded globally via `nuxt.config.ts` head scripts.
To trigger the messenger from any button:

```html
<button onclick="openIntercom()">Chat with us</button>
```

## Deploy

The site generates as static HTML. Deploy to any host:

- **Vercel** — `vercel deploy` (auto-detects Nuxt)
- **Netlify** — drag `.output/public` to the dashboard, or use the CLI
- **Cloudflare Pages** — `npm run generate` then upload `.output/public`
- **Any static host** — same upload story

For SSR (if you want server-side rendering instead of SSG), remove the
`nitro.prerender` block in `nuxt.config.ts` and deploy to a Node-capable host.
